# Community expectations

Be welcoming, patient, and respectful. Discuss code and decisions without personal attacks. Different experience levels, backgrounds, identities, and communication styles belong here.

Harassment, discrimination, threats, sharing private information, sexualized conduct, and repeated unwanted contact are not acceptable. Do not publish someone else's customer data, credentials, or private communications.

These expectations apply to repository issues, pull requests, discussions, reviews, and other spaces maintained for Fieldwork. Maintainers may edit or remove harmful content, pause a discussion, or restrict participation. They should explain actions where doing so does not expose private information or worsen harm.

For a conduct concern, contact the maintainer through the contact method on [Tedy's GitHub profile](https://github.com/tedy69). Avoid posting sensitive details in a public issue. Reports will be handled as privately as practical, with proportionate action and an opportunity to clarify misunderstandings.
